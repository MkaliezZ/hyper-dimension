# 首期开发状态与下一步（2026-09-26）

口径：仅以本仓库可运行代码为准。当前所有学生、监护人及教师资料均为模拟测试资料；本地工具和 API 不等于生产身份系统或公开 A2A 服务。

| 层次 | 已有证据 | 当前状态 |
| --- | --- | --- |
| 产品与命题设计 | 多教材核查规则、英语评测 Skill、原创样题和 2026 公开考试样本核验 | 方法设计与样板阶段；真实教师校准及评分效度验证未完成 |
| 0. 样板与契约 | 教育协议 v1 请求/结果，1.1 档案与展示命令/结果 JSON Schema，A2A v1 JSON DataPart 校验，课程单元 Schema | 已具备严格结构化契约；尚无正式 A2A 网关、Agent Card、真实互通和试点教材页码冻结 |
| 1. 业务底座与身份 | SQLite 评测表、稳定 student_id、随机学生访问码、私有档案版本、SHA-256 摘要、审计事件、出题及作答幂等 | 本地模拟数据闭环；教师/监护人生产身份、PostgreSQL 和恢复流程未完成 |
| 2. 测评与报告 | DeepSeek 适配器、本地策略出题/评分/自动批准或复核、报告与完整证据快照归档 | 模拟数据可运行；语义正确性、量规与教师审批仍需校准 |
| 3. 教师 Agent | 本地 stdio MCP 工具：档案读取与版本编辑、幂等出题、报告/错题/归档读取、私有展示草稿 | 可测试的工具适配；云端托管、生产授权和限额未完成 |
| 4. 教师与学生网页 | 2D 静态视觉基线；注入教师令牌的本地教育 API；学生随机访问码加签写姓名提交 | API 可验收，教师编辑页和学生答题页尚未完成；当前不能接真实学生 |
| 5. 公开成果展示 | 独立发布许可、来源归档、教师 API 发布、板块选择、撤回后停止公开读取 | 仅本地后端；监护签署核验、2D 板块接入与公开前审查 UI 未完成 |
| 6. A2A、多端与硬件 | A2A DataPart 业务意图校验；设备协议设计 | 真实 A2A 端点、学生 Agent、ESP32-S3 联调尚未实现 |

## 下一段可验收开发

1. 冻结一位试点教师、班级和已核页教材单元，校准题目质量门、报告解释、教师预授权策略和监护授权证据。
2. 建立生产教师/监护人身份网关、租户/班级权限、PostgreSQL 迁移、密钥与档案存储保护；再允许处理真实学生。
3. 将本地教师 API 和 MCP 服务接到同一云端业务服务，完善限额、拒绝/复核、恢复与审计。
4. 在 2D 视觉基线中做教师可编辑档案、策略和成果发布界面以及学生答题页；公开展示只读取已发布且许可有效的数据。
5. 在这些业务语义冻结后接学生 Agent 的 A2A Agent Card/端点，使用相同 Schema、身份与授权规则做跨 Agent 兼容测试。

MCP 降低参数格式错误，不能阻止模型选错动作；A2A 解决 Agent 之间的任务传递。敏感操作的最终约束仍在服务端。参见[教师 MCP 与 A2A 业务契约](teacher-mcp-a2a-contract.md)。
