## 下一段最小可验收开发

1. 选定一位试点教师、一个班级及一册已核页的英语教材，冻结教师预授权策略、读写题型和首个验收样板；用 [题目生成流程](../skills/english-assessment/references/item-generation-workflow.md) 校准真实 Agent 题包。
2. 把当前 SQLite 本地模型迁到 PostgreSQL，并加入身份、租户/班级授权、完整审计与 worker 恢复；质量门补上题目语义和答案唯一性的人工校准样本。
3. 将已验证的本地闭环接成受控 API：`teacher policy → generate item/answer/rubric → quality gate → submit response → auto score/approve → report/archive`，只在生产授权、存储加密和监护同意范围核实后接真实学生。
4. 把同一 API 接入 2D 风格的教师卡片入口和学生轻页面，再接教师 Agent 白名单工具。听力/口语按实际媒体和量规准备情况逐步加入；学生 Agent、A2A 和硬件不阻断这个纵向切片。

**当前开发位置：本地自动评测核心已跑通，下一步是 PostgreSQL/受保护 API/教师与学生页面；尚未达到真实学生可用的生产服务。**
