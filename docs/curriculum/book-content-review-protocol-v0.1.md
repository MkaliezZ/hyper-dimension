# 多版本英语教材全文复核规范 v0.1

状态：复核流程，尚未完成教材全文审阅。适用范围为 6—15 岁、义务教育 1—9 年级；五四制六年级按初中起始年级单列。目录、书名或“最新版”标签不能替代正文证据。

## 证据分级

| 等级 | 已实际核对 | 可用于 |
| --- | --- | --- |
| E0 索引 | 第三方列表中的书名、版次标签、链接 | 建立待查清单 |
| E1 目录 | 目录页与单元题名 | 候选主题映射；不得断言具体教学内容 |
| E2 单元正文 | 完整查看该单元各页、任务、听力/口语入口与评价页 | 单元内容分析及候选教学包 |
| E3 全册正文 | 从封面、版权页到最后一页逐页核对，登记缺页与不可读页 | 全册教学进度和纵向比较 |
| E4 二人复核 | 第二人复核教材身份、关键页及分析结论 | 正式教材适配与发布 |

若音频、视频、教师用书单独提供，分别记录其可用性；“已核对课本正文”不代表这些配套资源已核对。

## 每册检查项

1. 身份：出版社、编写单位、系列/地域版本、六三或五四学制、ISBN、修订年、印次、年级、册次、学校实际使用版本。
2. 完整性：封面、版权页、目录、正文和附录的页数；缺页、重复页、模糊页；正文来源及访问日期。
3. 逐单元结构：主题、大问题/情境、学习目标、输入材料、听读任务、口语独白/互动、书写、语音拼读、语法词汇、项目/迁移、评价与复习。
4. 逐课任务：学生具体要完成什么、受众和交际目的、所需先备能力、教师支持、预估课时；区分必学与拓展。
5. 分层与口语：识别支持低起点学生的脚手架、可采集的发起/追问/澄清/回应证据，以及教材未覆盖的真实表达需求。
6. 结果：映射 C01—C08，标注教材支持程度、缺口、超前要求和建议的原创补充任务；不从年级或单次测试直接推断 CEFR 等级。

复核记录只保存页码、任务类型、简短转述、结论和证据引用；不将教材正文、图片、音视频复制到公开仓库。涉及教材的具体产出先经过教师审核。

## 每册记录格式

- book_id、grade、stage、publisher、series、school_system、volume、revision、ISBN；
- source_url、local_source_ref、source_access_status、reviewed_at；
- toc_status、content_status（未访问/单元已阅/全册已阅/二人复核）、pages_total、pages_reviewed、missing_pages；
- unit_id、page_span、input_tasks、output_tasks、oral_evidence_opportunities、literacy/phonics、assessment/extension、C01—C08 映射及置信度；
- reviewer、second_reviewer、unresolved_questions、change_to_curriculum。

每一条教材映射须能回到具体版本和页码。目录抽取结果的 content_status 一律为“未访问正文”。

## 对现有 v0.1 设计的复核门槛

- 现有两个样板是原创补充教学方案，未逐页核对对应教材正文；不得称为教材配套教案。
- 重新检查 6—8、9—12、13—15 岁分组是否符合教材实际难度、任务复杂度和学校课时；五四制六年级单独检查。
- 对照教材真实的听说读写及项目任务，修订能力节点、单元任务、口语量规和每日/每周/每月测评负担。
- 出版社版本和印次变化可改变课文及活动；发现冲突时新增版本记录，不覆盖旧记录。
- 全册未达到 E3 时，仅可发布“目录级假设”；E4 后再将相应教材适配标为正式。
