# 班级共同目标与学生动态进度对齐 v0.1

状态：教师版首期必做的业务契约；目前尚未实现跨学生计算、分组建议、计划版本或教师页面。现有代码仅在学生记录中保存自由字符串 school_progress，不能把它当成已实现的动态对齐。

## 目标与边界

“对齐”是让不同起点的学生参与同一个教师确认的单元里程碑，同时给每人不同的前置支撑、练习和迁移挑战；不要求所有学生同速、同分或同一题。教师版先完成，学生 Agent 后续只读取本人获准计划。首期读写证据可用；听力、口语证据在相应评测质量门完成后接入。学校年级、教材授课进度和学生能力证据是三类不同信息，不互相代替。

## 一次周度对齐的输入

1. 教师批准的班级里程碑：岛/班、教材 edition_ref 和 section_ref、能力节点、共同任务、达成证据规则、目标时间、策略与版本。教材版本未核准时仅用跨教材能力节点和原创任务，不能猜页码。
2. 每名学生的可信状态：实际年级、个人学校进度、最近获批准的读写作答、题目/量规/模型版本、能力节点、任务难度、提示强度、错误标签、复测时间及异常状态。未审批的模型判断不得作为已掌握证据。
3. 比较规则：只比较已映射到同一能力节点且任务构念可比的证据；不同卷型的原始总分不能直接排序。跨教材需要已核准的节点映射。数据不足、评分冲突或过期时返回待补证，而不是把学生归为低水平。

## 建议计算与教师决策

服务端在每次获批准的新证据后更新个人能力快照；每周或教师主动触发时，以固定的规则版本和输入快照生成一次不可变对齐建议。初始规则由教师校准，建议含共同目标可参与度、缺失的前置节点、证据强度、原因引用、下一任务、复测条件和下次检查日期。Agent 可解释和起草差异化任务，不能直接改写证据、阈值或批准状态。

- 前置支撑：有足够证据表明关键前置节点尚需支持；给短时脚手架及可重新参与共同任务的退出条件。
- 核心练习：前置节点已具备，但共同任务的独立完成证据不足；练习同一目标并逐步撤去提示。
- 迁移挑战：共同目标在至少两次独立任务中稳定完成，且包含新情境；给不同受众或情境的迁移任务。
- 待补证：证据不足、不可比、质量门失败或结果冲突；安排最小补测，不把“待补证”当作能力最低组。

上述分组只是会随证据变化的教师教学建议，不是学生永久等级。教师查看证据后确认、修改或拒绝建议；人工改动保存理由与版本。教师预授权可允许不改变分组的常规练习自动派发，但共同目标、分组及公开报告的高影响变更仍由服务端策略和教师确认控制。

## 版本化业务对象与接口

- class_milestones：共同目标、教材版次/章节、能力节点、目标日期、达成规则、教师确认人和版本。
- student_capability_snapshots：按学生和能力节点记录证据引用、支持强度、最近独立表现、覆盖、置信原因及生成规则版本；可从已批准事件重算。
- alignment_runs 与 alignment_recommendations：输入快照摘要、规则版本、每名学生的建议组别、原因、下一任务和待补证项；跨学生原始内容只在教师权限内读取。
- alignment_decisions 与 plan_revisions：教师确认/覆盖/拒绝、原因、发布范围、四周个人计划版本和审计事件；不覆盖历史。
- 教师私有 API 先设计为“设置里程碑 → 预览对齐建议 → 教师确认 → 生成任务/计划 → 查看本周变化”。精确路径和 OpenAPI 在业务服务实现时固定。未来 A2A 沿用现有 plan.read.v1 读取本人已批准计划，不新增可枚举其他学生分组的操作。

学生档案和月度报告引用所属里程碑、对齐运行与个人计划版本；教师页面显示班级目标覆盖、前置支撑人数、共同错误、待补证和待复核，而不公开同伴排名。公开小岛只可展示单独审批的匿名或获准案例，不展示班级明细。

## 开发顺序与验收

1. 随共享教材目录建立教师确认的里程碑和能力节点映射；将现有自由字符串 school_progress 保留为迁移源字段，不直接作为版本化教材坐标。
2. 在 PostgreSQL 中加入上述表、关系约束和审计；复用现有 AssessmentService 的已批准读写证据，生成可重算快照与一次周度建议。
3. 接入教师受保护 API/MCP 与“班级进度”页面：教师看到建议依据、确认或覆盖原因，并可预览各组不同任务及每人四周计划。
4. 接入报告归档和本人计划读取；学生只看到自己的目标与反馈。听说、跨 Agent 读取随对应能力上线。

最小验收使用四名模拟学生：支撑、核心、迁移、待补证各一人；同分但提示强度不同不被机械归为同组；新增复测证据后建议可以变化且旧版本仍可审计；教师覆盖不会改写原始作答；跨班/跨岛读取被拒绝；学生端与公开岛不显示他人分组或排名。测试使用固定输入，验证同一规则版本可复算同一结果。没有这些证据前，开发状态只能写“已设计，未实现”。
