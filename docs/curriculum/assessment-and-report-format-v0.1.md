# 测评蓝图与书面报告格式 v0.1

状态：待教师与试点证据校准。所有分数、阈值和样本均为教学设计，不宣称标准化考试效度或 CEFR 认证。

## 1. 测什么

首轮诊断按学生年龄选择适宜形式，每个能力节点至少有“听/读获取信息”和“口头/书面完成意图”两种观察方式；口语另分独白与互动。任务跨度覆盖前置目标、当前教材单元目标和一个邻近挑战目标。学校年级决定任务入口，不能决定结果。

一次诊断可给临时学习起点。稳定层级至少需要两个独立任务，优先跨天，并记录题目版本、情境是否练过、提示强度、媒体质量和教师复核。证据不足、设备失败或评分冲突时返回 insufficient_evidence 和补测建议，不能强行给 L0。

## 2. 四层节奏

| 周期 | 学生任务 | 输出记录 | 教师动作 |
| --- | --- | --- | --- |
| 每次学习后 | 3—5 分钟出口任务；低龄优先口头、图像、实物 | 单次能力节点证据和错误候选 | 查看异常即可 |
| 每周 | 新情境的综合任务，至少含一次交流产出 | 任务完成度、互动/书写表现、旧错复测 | 审核异常和分层安排 |
| 每月 | 汇总已有证据；仅对缺口补测 | 多维报告草稿、作品前后对照 | 审批学生/家长可见版本 |
| 每学期 | 跨主题迁移与目标回顾 | 能力画像、下学期目标建议 | 与学生/家长确定计划 |

这是可配置的教学节奏；不得把每日练习默认实施为频繁正式考试。

## 3. 口语量规

每次任务在五维分别记 0—3：意图达成、主动发起、回应与澄清、信息完整、可理解度。0 表示证据不足或未完成本次任务，不等于学生能力为零；1 为大量支持下部分完成；2 为熟悉情境较独立完成；3 为新情境能迁移。教师同时记录提示次数、是否直接示范、音质、原话或时间片段、可接受的不同表达。准确性作为支撑说明：仅当词句错误影响意思时，才显著影响交际维度。不能以口音接近某种母语者为主要评分标准。

开放题和口语评分流程：模型给草评及证据引用 → 教师回听/查阅 → 修改理由 → 确认评分版本 → 报告引用确认后的版本。模型不得直接写已批准分数。

## 4. 教师报告固定字段

报告记录本身至少包含：report_id、schema_version、student_ref、class_ref、period_start/end、textbook_edition_ref、unit_package_refs、capability_results、evidence_refs、rubric_versions、coverage、confidence_reason、school_progress_comparison、priority_goal、four_week_plan、teacher_notes、approval_state、approved_by、approved_at、visibility_scope、audit_event_refs。外部展示使用假名或授权姓名；公开岛案例另走独立的脱敏和授权审批。

书面页面按以下顺序：

1. 本期背景：教材、单元、真实授课进度和本次证据覆盖。
2. 一句话结论：当前最值得练习的交流任务，附证据强度。
3. 分维能力：听、说的独白、说的互动、读、写，以及词汇/语法/语音支撑。
4. 证据卡：任务、原作答或受控音频片段、教师认可解释。
5. 错误与不确定：观察到的行为和可能原因分开写。
6. 四周计划：共同班级目标、个人脚手架、每周任务、复测条件。
7. 审批与可见范围：草稿、批准、分享或撤回及版本。

## 5. 虚构示例：三年级“班级物品服务台”

学生代号 S-DEMO-01。教材坐标为人教新版三年级上册 Unit 2 School things，能力目标 C01/C02/C04。两次不同物品组合中，该生能听辨所需物品；第一次需教师示范提问，第二次在提示卡支持下主动请求并确认。当前可写：“请求与确认已出现可观察进步；独立发起尚需一次未练过的情境复测。”不可写：“该生英语真实水平为 A1”或“口语能力差”。

下周目标：在没有完整句型卡时，能向同伴提出需求、核对一项特征并回应。支持方式：保留图片、移除完整台词；周末换成借书场景复测。教师若认为音频模糊，可把该次口语标为待补证。

## 6. 与业务 Protocol 的关系

报告是经过授权的业务对象，不是 A2A 消息正文。未来 hd.education.feedback.request.v1 只返回已批准、符合本人权限的 report_ref 或适龄摘要；未批准时返回 pending_review。所有证据引用由服务端解析并检查班级、学生、授权和可见范围。教材映射更新不覆盖已经发出的报告；新判断应形成报告新版本。
