# 演示素材来源

- public/island-foreground.webp、public/sky-background.webp：Hyper Dimension 2D 小岛演示中形成的双层岛图；在本仓库仅作可替换的 DEMO 视觉。
- public/profile-island.png：Hyper Dimension 小岛演示中生成的虚构岛主头像；仅作可替换的 DEMO 头像。
- public/banner_*.png、public/header_banner_*.png：来自上游 Astro 2D 演示；保留其 MIT 许可文件 LICENSE.UPSTREAM。
- public/icon-*.svg、public/favicon.svg、public/divider_line.svg：本仓库新增的原创矢量演示图标与装饰。
- public/media/：默认不含视频。用户可加入自己的图片或视频并在卡片配置中引用。

模板曾使用的外部图标包未复制到此仓库。用户自带素材的公开展示、再分发及人物肖像授权应由提供者确认。
