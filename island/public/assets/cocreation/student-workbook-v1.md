## 本机环境

准备完整的 Agent 源码包；推荐 Node.js 24、Python 3.11。在游戏目录用终端执行。macOS 将 `--python=python` 换为 `--python=python3`。

```text
node tools/agent-deploy.mjs plan
node tools/agent-deploy.mjs doctor --python=python
node tools/agent-deploy.mjs setup --python=python --offline
node tools/agent-deploy.mjs verify
node tools/cocreation-check.mjs
node tools/agent-deploy.mjs run --mode=lan
```

打开 `http://127.0.0.1:4175/`，用启动终端显示的加入码注册自己的岛主账户，再回到小岛。已有授课服务器时使用教师提供的地址与加入码，每位学员使用独立账户。已经运行的副本不重复启动。共创练习不需要模型密钥；交换作品只发送 .hdpack.json。端口占用时先核对对应进程。

## 操作路线

1. 后台 → 共创工坊 → 潮汐茶席模板。修改编号、作者、标题、目标和提示，保存草稿。
2. 从版本页导出，检查字段。完整JSON可以放最多6个挑战，关联recipeId必须属于现有图纸目录。
3. 提交审核。提交会冻结版本摘要；审核说明至少4字，写明可完成性和建议。
4. 审核通过后启用版本，点击「岛内试玩」。观察后配对，完成后保存共创成绩。
5. 关闭工坊、重新打开，确认成绩的作者与版本。正常收起保留关卡，明确结束才取消本局。
6. 编辑下一版，改一个关卡参数或一条提示；保存、提交、审核、启用v2。
7. 回退曾启用过的v1，确认旧标题和种子；导出两个版本并截取成绩。
8. 切换另一个画风查看同建筑素材，重新打开工坊，确认同一作品、版本和成绩。两种画风共用本岛工坊，不重复导入。
9. 将导出的内容包交给另一位实际学员。对方在自己的账户导入、阅读说明、审核并试玩；记录卡点。对方的小岛保存的是独立副本，修改不会自动覆盖你的原件。
