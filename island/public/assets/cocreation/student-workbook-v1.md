## 本机环境

需教师提供含代码和完整素材的项目副本。推荐Node.js 22或更新的受支持版本；在项目根目录用终端执行：

```text
npm install
npm run cocreation:check
npm run dev:pixel
```

另开终端运行 npm run dev:origami。访问 http://127.0.0.1:4173/ 与 http://127.0.0.1:4174/ 。已经运行对应服务则不重复启动。命令不包含密钥；不要将个人 .env.local 或存档发送给他人。共创练习无需调用AI。端口占用时先由教师确认对应进程，不能批量结束所有Node进程。

## 操作路线

1. 后台 → 共创工坊 → 潮汐茶席模板。修改编号、作者、标题、目标和提示，保存草稿。
2. 从版本页导出，检查字段。完整JSON可以放最多6个挑战，关联recipeId必须属于现有图纸目录。
3. 提交审核。提交会冻结版本摘要；审核说明至少4字，写明可完成性和建议。
4. 审核通过后启用版本，点击「岛内试玩」。观察后配对，完成后保存共创成绩。
5. 关闭工坊、重新打开，确认成绩的作者与版本。正常收起保留关卡，明确结束才取消本局。
6. 编辑下一版，改一个关卡参数或一条提示；保存、提交、审核、启用v2。
7. 回退曾启用过的v1，确认旧标题和种子；导出两个版本并截取成绩。
8. 切换另一个画风查看同建筑素材，分别确认界面。每套画风有独立共创档案，可导入相同包。

- [ ] 一条下一步改进

我的挑战包只包含声明式说明和参数；引用游戏原有素材，不自动包含或重新授权岛内美术。试玩不产出正式物品。正式制作需通过原配方与原材料流程。

遇到错误先记录原提示，保留待核对请求；不要多次新建同一动作。服务关闭时草稿表单可暂存在浏览器，但已保存的作品、版本和成绩在服务的 _cocreation 目录。突然关页最多丢失未确认的最后一批操作，已确认版本与成绩不会因浏览器清缓存消失。
