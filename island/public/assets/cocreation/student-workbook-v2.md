# 学员练习册 · 正式物品共创

## 一次准备好

- 作品名称、作者署名、介绍与授权方式。
- 两件物品各自的用途、关联建筑、等级和材料。
- 每件物品的像素／折纸 PNG：32–512 像素，8 位非交错，不超过 256 KiB。
- 第一件组件的基础材料，以及第二件成品所需的组件和其他材料。普通游玩可采集；课堂演示岛若预置物资，要明确标为练习夹具。

## 在游戏中完成

1. 打开后台 → 共创工坊 → 新增正式物品包。
2. 改作品编号、作者、介绍和授权。设置第一件组件的名称、建筑和用途。
3. 用“添加材料”选择原料，修改材料数量对照表。上传双画风 PNG，并检查预览。
4. 再添加一件成品，材料包含第一件的 `@编号`；前置配方也填该 `@编号`。上传对应的两张 PNG。
5. 选择本作品的关联图纸，写清挑战说明和提示。保存草稿；确认没有循环依赖或缺失图片后提交审核。
6. 写审核说明并启用，在关联建筑正常完成小游戏。核对背包实际扣料、产出一件，以及后续加工或赠礼结果。
7. 导出所选版本，让另一位岛主从工坊导入。接收方审核启用后，用自己的库存再做一件。
8. 修改名称或图片形成 v2，再回退 v1；核对作者、图片、旧成品和制作回执仍然对应。

## 制品怎样带来经营收益

1. 从背包打开成品详情，确认用途、售价和可出售的场馆，进入货架并主动上架。发布配方不会自动上架商品。
2. 核对留用数量：非食品默认保留一件。可以再制作一件供出售，也可主动设为零；任务已预留的物品不可出售。
3. 等游客实际到店、体验和购买。记录物品数量变化、成交收入、经营成本与净收入；未成交就写“等待购买”，不把预计售价计入实际收益。
4. AI 可用时，可让管家指派组件与成品的顺序制作；刷新后核对同一任务继续，库存不重复增加。未配置模型的课堂仍可手动完成。

## 展示时说明

展示自己的实际素材和制作结果，区分自创内容与内置素材。不把占位图片称为成品美术，不把自动测试称为真人授课或多设备实测。记录一次失败、原因和修改结果，保留原版本后再改。

旧版仅调整已有小游戏的挑战包仍可使用；“从茶席挑战开始”入口保留。新增正式物品包包含素材附件，文件可能大于旧的 48 KB 纯文本模板，但日常存档不内嵌图片。
