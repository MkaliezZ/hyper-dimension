# 居民住所：由生活习惯决定布局

## 空间原则

每位居民拥有独立户型。职业决定主要家具，性格决定开放或安静的空间，喜好和经历决定陈列物。入口、通道、床位、工作台、会客位置分别设计，不能只替换同一个房间的颜色与摆件。

同一住所在像素与折纸画风下保持相同的家具位置和动线；两种材质各自绘制。地图入口、居民身份和存档始终对应原有 ownerId。

室内操作继续使用房屋弹窗。玩家点击地板绕行家具，走到互动点后再展开内容；原有角色外观、八向朝向与连贯动作继续使用。读到的农田、配方、邻里记忆和休息状态来自当前小岛。

## 当前接入范围

- 麦穗小舍与木榫居已制作独立的双画风内景，使用各自校准的地板和家具碰撞区域。
- 育苗排列按游戏日和目标季节生成，仅使用游戏内适季作物；同一行、列与四格小区各有四种不同作物。提示只补一个合法空格。
- 木片拼画从完成状态进行合法打乱，关卡每日变化，支持退一步和查看原画。服务端回放实际滑动序列后接受完成记录。
- 两种家中消遣只留下手账，不生产物资或金币。记录保存在本机服务端，同一天重复完成不会重复增加天数；关闭窗口后的迟到回执不能重新弹出旧界面。
- 其余 14 户仍需逐户制作内景、校准动线并接入自己的互动。表中的布局是制作约束，不代表这些房间已完成。
