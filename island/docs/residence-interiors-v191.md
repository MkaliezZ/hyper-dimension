# 居民住所：由生活习惯决定布局

## 空间原则

每位居民拥有独立户型。职业决定主要家具，性格决定开放或安静的空间，喜好和经历决定陈列物。入口、通道、床位、工作台、会客位置分别设计，不能只替换同一个房间的颜色与摆件。

同一住所在像素与折纸画风下保持相同的家具位置和动线；两种材质各自绘制。地图入口、居民身份和存档始终对应原有 ownerId。

室内操作继续使用房屋弹窗。玩家点击地板绕行家具，走到互动点后再展开内容；原有角色外观、八向朝向与连贯动作继续使用。读到的农田、配方、邻里记忆和休息状态来自当前小岛。

星野家采用弧形观测窗，床位藏在短书架后，左前天气桌、后侧星图桌与右侧望远镜由同一片地面连接。首张生成图的隔墙挡住通道，已经重绘；游戏碰撞按修正后的布局校准。天气桌显示当前岛屿的季节、时刻及雨雪影响；桌上星图是明确标注的虚构观测练习，按方位、颜色、亮度和观测顺序连星。

两项活动每天变化，完成后保存到同一服务端手账；重复提交不增加金币、物资或当日完成天数。两种画风维持同一户的家具位置和存档身份。活动侧栏放宽，缩小桌面图盘并将来宾卡排成一行，使线索集中可读；窄屏保留独立家具快捷入口。

早餐计划每天改变两份面团各阶段的耗时。玩家安排揉面、醒发、烘烤和冷却，既要遵守前后次序，也不能让同一工位被两份面团同时占用，并须在截止时段完成。时间表可演练，进度线和步骤亮起对应实际安排。它是家中的计划练习，完成保存手账，不凭空生产面包。

南风的光影斋采用不规则 L 形地面：入口经四幅风景展墙走向窗边构图桌，右后为独立显影区，前右卧榻旁是低矮收纳柜。初稿高屏风挡住暗房动线，已改为矮柜；像素稿多出的地面盆栽也已去除。显影台保留一部放大机、三只浅盘，相机与空三脚架分开摆放。

光影四帧使用这间房真实加载的美术作为取景素材。玩家拖动取景框、调整镜头，依次完成采光窗、相机、显影盘和展墙的构图。服务端验证主体完整性、镜头范围及构图点，四张裁切结果写入同一相册，刷新或换画风后继续展示对应素材的同一构图。界面明确这是构图练习。

## 听潮屋与白草居

小满的听潮屋在右前入口设泥靴与雨衣区，低矮隔断保留宽阔绕行通道；右墙是钓具准备台，海窗下有潮汐本，左后是圆窗下的干燥床铺。鱼拓、贝壳、个人餐桌与海岸记录体现安静独立、熟悉海况的生活。

潮汐行囊是每日行前演练：六件用品包装占位拼片填入六列四行收纳格，允许旋转和移出，避开固定隔格。轮廓上的亮点对应点击位置，凹形拼片旋转后也能正确定位。再按练习海况选择涨潮、风力不超过三格且无风雨的时段。演练海况明确与岛上实时天气分开；海窗互动仍展示实时天气。

洛白的白草居把两把接待椅放在前侧，采光桌与私人卧室留在后侧，以矮书架划分边界。初稿的中央高墙挡住床边路径，已改为后侧短矮架，并加强纸材折面。房间保留两杯一壶、一个放大镜、窗台三盆植物与单人床，反映认真照顾别人、也需要照顾自己的性格。

一页叶影使用六乘六的逻辑填图。行列数字描述连续叶片长度，玩家涂叶片、标空白，支持拖动连笔、擦除与整笔撤回。每日图案均由线索唯一确定；完成只保存观察手账。它是游戏内剪影练习，不生成现实医疗结论。
