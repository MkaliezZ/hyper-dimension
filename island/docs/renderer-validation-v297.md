# V297 · 人物贴图校验与地图操作响应

人物 GPU 绘制改用 WebGL2。初始化和贴图上传提交完成栅栏，通过零超时轮询让出主线程，完成后再检查链接状态与上传错误；保留上下文丢失处理、失败纹理释放和完整 Canvas 人物后备路径。已有动作缓存可在另一张贴图等待时继续使用，等待期间的临时后备画面不会写进 GPU 动作缓存。

人物数量、原图、关节网格、64 段连续动作插值、绘制密度、96 MiB 贴图与64 MiB 动作缓存预算保持。九项新增检查覆盖等待、错误、取消、上下文丢失、预算释放及已有缓存复用。默认1488项检查通过，两套画风192组原生渲染与发布版逐像素一致；原始人物工具／衣装、玩家权威操作、自定义作品制作和跨岛导入的双画风脚本通过。

Windows 四地图经过12秒并行动画后，真实点击获得服务端成功回复，回复被保留500毫秒，RAF／计时观察分别在554／555毫秒完成。保持原10秒点击与真实回复确认预算、3秒完成限制，四张地图均有实际 GPU 人物绘制且无上传错误。测试助手的确认时序已修正为等待真实回复，未修改游戏结果或放宽限制。

此四地图检查使用一个Windows进程、四个隔离虚构账号、历史不可变安装和七个当前渲染模块。它验证指定操作，不代表最终版本全部A2A／联合活动／经济流程、实体多设备、Mac实机或真人验收。更早初始化尝试与一次测试握手失败已保留；另观察到服务与测试助手共用的Node进程在启动期间长时间忙碌，业务根因仍在调查。托管Windows／Mac失败的恢复需要后续运行确认。最新宣传片画面继续使用V296；公开播放器流畅性仍待修复。
