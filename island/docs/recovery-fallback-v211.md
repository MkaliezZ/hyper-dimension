# V211 · 核对成功后可靠回岛

修正一个返回阶段的停留路径：作业和服务端进度已经核对成功，但浏览器取消首次 reload 后，旧页面持续暂停、按钮禁用，无法继续操作。

确认成功后仍封闭旧页面的写档和作业入口；正常离开页面会取消备用导航。若 1.5 秒后旧页面仍在原地址，则使用同源、同路径的全新地址重新进入，保留现有查询参数和锚点。玩家已经转往其他地址时不会被拉回。恢复按钮在等待期间明确显示“进度已核对，正在回岛”。没有清空存档、跳过回执或恢复旧页面的模拟。

## 验证

- 在独立虚构 LAN 岛通过 HTTP 204 取消第一次 reload。原实现的 Codex 内置浏览器停留在旧页，按钮禁用；新实现自动重新进入，恢复提示消失，可以打开背包。204 为测试注入，不能据此认定用户现场也收到了 204；用户现用页面和私人数据未被读取。
- 双画风原生用例覆盖首次 reload 取消、备用导航延迟期间的旧页面检查点、明确取消未完成作业、丢失取消回包重放、材料保留、唯一回执及连续三次刷新；原有断言保留。
- 单元覆盖正常离页撤销备用导航、取消 reload 后回岛、保留路径和参数、不干扰玩家另行导航、导航异常，以及此前的恢复隔离和保存排序。

这些是独立测试岛的自动化与内置浏览器操作证据，不是用户现用存档或物理多设备验收。
