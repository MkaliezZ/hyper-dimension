# V174 · 原生底图房屋落点校准

## 修复

V171 主要校准了贴图内的横向底座轴，地块的世界坐标仍源自总览母图。原生分块生成后，部分草坪及石阶发生位置偏差，旧的纵向落点使建筑压到台阶上。

V174 对像素、折纸各 25 座生产建筑和 16 座住所，分别记录原生合成底图中的可建草坪边界、门前横轴和石阶上沿。木作工坊、邮局的不规则地块按上层可建台地人工校准。潮汐船屋、船坞、露营站、邮局的横向和纵向偏移已修正。窄地块限制整栋房屋宽度，保持原贴图长宽比。

地图绘制、名称标签、前后遮挡排序与点击身份使用同一个几何计算。两主题共享校准后的地面碰撞范围，预计算通路已重新生成；原建筑 ID、住所主人、业务入口和存档身份保持不变。

`?align=1` 可查看黄色的实际草坪边界/中心、青色门前落点、白色贴图边框和通往业务入口的连线。校准数据位于 `src/terrainParcelAnchors.js`；修改该文件后运行 `node tools/build-navigation-edges.mjs`。

## 验证

- 检视两主题全部 82 个实际贴图合成落点及四处重点建筑的前后对照。
- `tests/v174-parcel-alignment.test.mjs` 检查 82 个可见房屋点击对应身份、等比缩放、地面阻挡、四处真实坐标、全部入口可达及寻路源文件哈希。
- `tests/v169-geography.test.mjs` 检查两主题生产建筑、住所和公共区域的连续可行走路径，并验证全部奇观摆放不堵入口。
- 此次校准不代表新的全平台或真人验收结论；云端结果以当前提交的 Actions 为准。

- 完整本地规则回归：984/984 通过，0 失败、0 跳过。
