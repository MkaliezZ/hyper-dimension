# V147 · 双画风鼠标 / Theme cursors

像素与折纸各有六种原创 SVG 鼠标素材：地图箭头、可交互箭头、拖拽、文字输入、禁用及保存等待。主题切换自动匹配，不使用系统小手作为主要图形。鼠标热点与箭头尖端对应，按钮中的图标也继承交互指针；地图取消拖拽后恢复默认状态。

素材尺寸 34×38 CSS 像素，小尺寸绘制；像素轮廓保持阶梯边缘，折纸轮廓保留纸面折线。没有引入额外每帧绘制或动画计时器。

双画风素材解码、各状态计算样式、按钮子元素继承及地图点击寻路／进入房屋通过本机 Edge 检查。

## English

Each appearance has six original SVG cursors: map arrow, interactive arrow, dragging, text input, unavailable and saving. Theme changes update the cursor automatically. Semantic hotspots match their shapes, button children inherit the interactive cursor, and pointer cancellation resets the map state. Native Edge checks passed for asset decoding, semantic cursor styles, child inheritance, movement and building entry in both appearances.
