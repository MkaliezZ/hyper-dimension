# 恢复控件的状态与生命周期

核对进度期间，独立作业控制器仍可能收到此前提交的回执、更新按钮状态或挂载提示卡。此前只在点击瞬间记录按钮的 disabled 值：新增控件没有暂停，核对结束又可能把旧 disabled 值写回，出现可点击却无反馈、或者重试仍不可用的问题。

现在由恢复流程持有交互锁。核对期间各作业卡使用 inert 暂停交互，控制器继续管理自身 disabled 状态；统一核对按钮显示等待状态，安全重新进入链接保持可用。最后一张作业卡退出时，尚未结束的核对仍持有提示区；完成或失败后重新计算界面状态。
