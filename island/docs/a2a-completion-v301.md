# V301 · A2A 工具答复续做

完整四岛隔离流程中，原机管家在一轮提议里只说“我先读取真实资料”，即结束文本回复；该轮只有一次真实 Flash 调用、零次工具调用。程序正确拒绝将其登记为协作成功，但此前没有继续这项未完成的协作。

现在只对尚未登记结果、未报告运行失败、调用计数和历史均可核实的轮次，使用同一个 Hermes Agent、会话和历史继续一次，并从原六次调用预算中扣除已用数量。模型失败、预算耗尽或缺少计数时不自动重试。观察工具必须先执行；纯文本、未核验确认和重复答复仍被拒绝。入场预留、交付及扣款继续由各岛主明确确认后的服务端事务执行。

八种离线行为检查覆盖意向文本续做、重复文本失败、模型失败不重试、预算耗尽、先观察、重复登记和未核验确认。实际 Hermes 工作线程中，故意先返回意向文本后，继续观察、调用答复并结束，总计四次调用、一个持久化会话、一条登记结果；该项使用确定性本地模型夹具。另一次真实 Flash 双管家流程完成提议、核对、岛主执行预留及确认，三条记录保持父子关联，真实预留十二岛币和两份木头。

原真实模型检查的初始资源夹具改为首次保护存档之前声明，继续保留后续客户端篡改库存的拒绝规则。原检查的回执、关联、物资与调用断言保留。旧四岛失败和初始夹具错误证据均保留，没有重标为成功。
