# V300 · 角色 GPU 工作线程

隔离四岛记录确认，一次WebGL错误查询在主线程阻塞超过70秒；后续也捕获到活动画布尺寸重设及位图复制的停顿。本次将角色GPU上下文、着色器、贴图上传、完成围栏、错误检查和骨骼光栅化移到独立素材工作线程。主线程继续负责游戏状态、工具触点、资源回执和输入，只接收已验证绘制结果。没有删除GPU错误／内存／上下文丢失处理。

原生网格、着色器、64步姿态插值、缩放密度、人物数量、动作和900秒有效日不变。匹配原300×150初始视口，保留原裁剪与采样。双画风、正／侧身、四种动作、三种缩放共192组像素逐通道完全相同，且候选分支未在主线程创建WebGL上下文。另64组实际旧版高清缩放工作线程与新素材解码器的GPU上传字节完全一致。曾失败的透明边缘、CPU裁剪与近似预览重建记录保留；这些失败方案未作为合格结果发布。临时预览仍按原方式绘制，高清素材就绪后才缓存GPU姿态。

临时绘制画布按精确尺寸复用，最多32个、常规4MiB；姿态图集仍64MiB、GPU贴图仍96MiB，待回传队列最多32项／16MiB。单独较大姿态保留原可绘制范围。活动位图不被主线程重复创建或转移走；工作线程根据同源原图和原缩放操作构造素材。返回位图使用后显式关闭，失效回复和超时释放队列，避免跨主题缓存污染。参见[位图生命周期](https://developer.mozilla.org/en-US/docs/Web/API/OffscreenCanvas/transferToImageBitmap)与[WebGL阻塞查询说明](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/WebGL_best_practices)。

当前完整源码的四个原生地图同时运行，未启用调试器、SAB、额外隔离头或观察器。四个GPU工作线程均就绪且实际绘制，上传错误为零；真实权威提交、暂扣500毫秒回复后，RAF观察920毫秒、定时观察1811毫秒完成，保留原10秒接受／3秒完成门限。初期未通过的四岛结果保留。此项是具体控制检查，尚不能替代完整真实模型四岛联合活动、长时间运行或实体多设备验收。

1510项规则检查通过。原始双画风角色／穿戴／工具检查每种解码224帧；实际采集与唯一结算重开、共创上传／制作／复用／赠送／跨岛导入，以及真实丢失移动回执重试均通过。角色热身后绘制样本的P95约0.5—6.4毫秒，仍保留最高约49毫秒冷启动样本，不宣称所有设备稳定60帧。新提交的托管Windows／Mac检查、最终包全新部署／持续运行、完整A2A联合流程、公开视频首播、OPC实际课程和5—8位新玩家验收继续。[机器可读范围](verification-v300.json)。
