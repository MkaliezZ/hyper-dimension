# V289 · 可见关卡计时与真实断线检查

## 行为

工作台以可见现实时间推进规则，并拆为不超过 50ms 的原有物理输入。低帧率不再把四秒观察阶段拖成长时间等待；服务端仍逐项校验并回放真实输入。素材准备、开局、暂停恢复各自重置计时起点。超过两秒的绘制中断自动暂停，不扣除未看到的关卡时间；隐藏页面、用户暂停及等待检查点时保持冻结。

这项修复保证计时和回放一致，不代表渲染帧率提高。素材、动画帧、画质、谜题、难度和经济规则没有调整。

## 已执行的验证

- 声明只交付 1.5 次 RAF 回调／秒，双风格旧版七秒仅推进约 0.5 秒；修复后约 6.5–7 秒，四秒茶材观察正常结束。
- 双风格使用实际指针输入完成茶会，原服务端规则回放得到完全相同的成绩；每条时间输入仍不超过 50ms。用户／传输暂停冻结，2.7 秒真实回调中断会暂停并在继续后重新计时。
- 8 组赛舟、烟花、书画、厨房持续输入检查通过：暂停清除按键／按住状态，恢复没有幽灵操作。
- Windows 导航故障注入改为原服务端实际提交后截断原始响应。每种风格均丢失三次已提交回执，再以原请求手动核对；四次载荷一致，回放序列为 false / true / true / true。保留旧轮询、布局、无瞬时核对卡片和原时限断言。
- 82 项关联规则通过，覆盖 25 类关卡与 308 配方的规则、材料预留、去重、并发提交和动作回放。

在四张地图保留运行的联合活动诊断中，三位实际点击操作的虚构访客均完成挑战并取得服务端对应成绩。最后结算检查被测试拦截器错误断言版本冲突中断；完整断线结算、评分、重启和回岛尚未通过，继续使用真实提交后丢失响应的方式验证。
