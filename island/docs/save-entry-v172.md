# V172 · 保存占锁期间的小岛入口恢复

2026-10-13。适用单机服务与 4175 联机会客入口，像素和折纸共用修复。

## 原因与修复

`withHomeIsland` 为保证出行与原岛生产互斥，在保存期间持有联机档案锁。旧自动保存每次读取并完整校验历史备份，已有大存档的独立副本复测约 7.1 秒，超过该锁的 5 秒等待上限。`/play` 又通过同一锁读取身份，超时被通用 JSON 错误响应替换为整个页面。

身份、出行状态和小岛入口改为读取最近一次原子提交且通过校验的身份档案；写入和出行事务仍使用原锁。入口在暂时忙碌时返回可自动恢复的 HTML，API 保持 JSON 并提供正数 Retry-After。首次打开存档仅重试明确的忙碌拒绝；不扩展到领取奖励、导入或结果不明的动作。

自动保存按备份文件自身的创建时间安排周期，只需检查最新有效的自动备份。列出、淘汰及恢复备份仍完整校验，损坏备份保留。修复长时间离线后连续生成周期备份的额外开销。

## 验证

- 4 项新增规则测试：真实持锁超过 5 秒时身份和入口仍可读，写事务超时不在稍后执行，退出后鉴权立即失效；HTML 自动恢复及出行跳转；损坏身份档案拒绝读取；备份周期、重启及损坏备份保留。
- 完整规则回归 967/967 通过；其中 30 项相关既有规则测试通过，覆盖身份隔离、HTTP 边界、出行与生产互斥、存档恢复和地形迁移。
- 真实浏览器对像素和折纸各执行一次入口忙碌 + 两次打开存档忙碌，均自动恢复到 `/play`，无页面脚本异常。使用虚构身份、隔离服务，不调用模型。
- 两份相同私有副本（约 3.3 MB 当前档案）的对照：旧版带周期备份 7.03 秒，后续两次 6.96 / 3.50 秒；修复版带周期备份 3.89 秒，后续 0.540 / 0.543 秒。此为本机服务端事务耗时，不能等同于所有设备帧率。
- 本机更新前完整备份验证通过，更新四个运行文件时 816 个受保护文件（含配置）的哈希完全一致。私人存档、日志和测试副本均不公开。

V170 仍是已完成六项平台检查的公开源码包。V171 的 CI run 38364604214 为 2 项成功 / 4 项失败，涉及移动测试时序/逐帧阈值及 Intel Mac 农田导航超时；本次本机修复通过不代表这些跨平台项目已完成。既有 V171 源码包保持原样。
