# V294 · 个人操作弹窗等待回执时的背景绘制

## 修改

衣橱等个人操作弹窗等待真实保存回执时，保留其被遮挡、模糊的海岛背景。窗口缩放仍按新的尺寸绘制，操作完成后恢复正常动画。游戏时间、人物动作、NPC决策频率、物资、保存及恢复协议均保持原规则。正在游玩的海岛画面不使用这项保留。

## 实际验证

隔离虚构账户提交真实的管家换装操作，服务端确认后暂时保留实际200回包。旧版在8个原生动画帧中重复绘制8次背景；改动后两种画风均为0次。改变窗口大小各重绘1次；收到原回包后显示已保存的选择，关闭弹窗后8帧恢复8次绘制，存档身份保持。此对照验证背景行为，不冒充Mac超时的本地复现或整机FPS结论。

既有完整管家衣橱测试的两种画风、全部13种选择、刷新持久化、390/768px布局及外来像素裁切检查通过。既有双画风恢复背景测试通过，保留原4秒点击门槛及物资进度检查。新的可部署测试已在本机完成，并加入平台检查，原有检查、条件、时限和断言未修改。

Intel Mac此前一次换装在真实200回包后仍未更新选择；改动后的平台结果尚待实际运行。四地图重启失败仍未关闭：重型浏览器追踪会影响原有对照，新增轻量计数未观察到贴图或姿势淘汰，因此不能把缓存抖动或某一绘制组件直接认定为已证实根因。
