# V336 · 就绪角色姿态先完成

角色绘制队列此前会先检查全部待处理贴图，只有它们都上传完成才开始绘制第一个姿态。这样，后面尚未准备好的贴图会阻塞已经就绪的队首。

现在按原来的先后顺序清理失效请求，并只准备当前队首。队首完成 GPU 绘制和独立位图复制后，才复用绘制表面并继续下一项。后续贴图的上传等待不再阻塞已就绪的队首。取消仍同时匹配姿态键与请求编号。

## 验证

25 项相关检查通过，覆盖三十一项冷贴图位于就绪队首之后、全部三十二项唯一按序返回、失效队首、取消、真实故障和位图所有权。原生浏览器使用公开 V335 模块作基线，只替换该 Worker：十组实际缓存 GPU 姿态逐像素一致，比较必须等待真实 Worker 缓存完成。

十五秒健康期限、请求数与内存上限、原图、网格、着色器、分辨率和插值均保留。本次源码不纳入尚未通过完整联机验证的主线程 GPU 补画、UI 或传输实验。

四地图联合运行仍有焦点及绘制稳定性问题；完整原机管家 A2A、联合活动收尾、新视频和真人／OPC 验收尚未完成。本次修复的范围是消除已证实的队列阻塞，不能据此宣称完整性能或产品验收通过。见 [验证记录](verification-v336.json)。
