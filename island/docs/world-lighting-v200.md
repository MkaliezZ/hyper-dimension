# 小岛的昼夜灯火

昼夜沿已有的共享世界时钟流动，两种画风、自己的岛和联机会客地图使用同一时令。环境光在日出日落时连续变化，界面面板保持自己的明亮色彩；没有能拦截鼠标的屏幕遮罩。夜景以实际灯具、住宅窗光、门前照明、广场路灯、灯塔与水面倒影共同表现。

## 灯光与生活

- 两种画风分别按各自建筑贴图标定位置；灯具没有借用建筑地块中心代替。
- 住宅窗灯随主人的作息熄灭；实际仍在岛上活动的主人可以保持窗灯。门灯和低位门前照明为回家保留路径。
- 营业和晚间活动时段、实际室内占用决定功能建筑的灯光；未建成的建筑不发光。
- 四盏主题路灯放在广场外侧的可通行位置，两套画风分别绘制木杆、灯罩和光晕。码头与会客馆的光点落在现有灯具上。
- 光晕纹理缓存复用，像素风保留阶梯光斑，折纸风使用柔和光晕与折面灯罩；不逐帧读取整幅地图像素。

## 海上的月影

月影放在码头外侧的开阔水域，按世界坐标绘制，拖动和缩放不会重启相位。月面切成随水波错动的横条，下方反光逐渐展开并变淡；当前月相取共享视觉日周期。晴夜最清楚，多云、雨、雪分别减弱可见度。白天太阳碎光保留，夜间不再继续闪太阳反光。

倒影只画在连到外海的水面上，孤立的蓝色屋顶不当作海。船体与码头的实际透明轮廓会从倒影层扣除，倒影不会盖上船身；缓存从原始美术提取的透明轮廓，直接裁剪反光，保留孔洞与细绳；不进行逐帧画布复制，也不重绘或改动地形资源。

## 时令接口

继续使用 `/api/world/environment` 和 `ENVIRONMENT_PROTOCOL = 1`，没有增加另一份昼夜存档。共享描述中的 `epochMs`、`dayLengthMs`、`phaseAtEpoch`、`rate`、`seasonDays`、`revision` 与 `source` 仍是统一总服务器的接入口。默认每视觉日15分钟、每季30视觉日。世界时钟独立于900秒有效经营日；离线时令轮换不会凭空产生经营收入或扣费。

室内家具与16户住所保留各自的动线和互动。居民的固定班次、休息、活动例外与未完动作回执继续使用已有作息逻辑，灯光仅显示这些状态，不改动任务或经济结算。
