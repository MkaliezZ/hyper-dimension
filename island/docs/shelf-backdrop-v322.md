# 商品弹窗背景与图像响应 · V322

## 调整

商品货架在小岛画面上打开时，保留已经绘制的模糊背景。模拟更新、经营与作业回执继续走原来的路径；窗口尺寸变化允许重绘，关闭弹窗后恢复小岛绘制。建筑内部及小游戏不匹配这一条件，资源、美术和动画算法保持原样。

## 故障取证与对照

托管 Windows 原生售卖检查出现 32px PNG 的 5 秒加载超时。完整隔离产物已校验 ZIP CRC 与 GitHub SHA-256。同一机器依次运行原版、静态背景候选与原版：首轮原版通过双画风，候选通过双画风，随后原版双画风再次触及图像时限；原版最后一轮观察到约 13.4 秒的响应，候选最大约 2.5 秒。

对照作业整体仍为失败，保留了原版负例；不会把它改称全绿。上述记录支持减少被弹窗遮住的世界重绘，不构成所有驱动或网络延迟均已解决的声明。原 5 秒 PNG、有限游客轮换、150 秒到店服务、售价 7／成本 3、库存、窄屏、转义与刷新断言均保留。

## 本机实际源码验证
