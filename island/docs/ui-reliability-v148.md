# V148 · 主题鼠标、画风切换与会客厅

## 修改

- 主题鼠标使用透明 PNG，保留原创 SVG；清理旧控件的小手／十字声明，子图标继承按钮鼠标。真正拖动后才使用拖拽指针。
- 身份轮询只在明确的 401 或成功响应中的账号变化时离岛；503、超时与不完整响应保留当前岛并重试。大厅首次连接同样区分暂时忙碌与身份失效。
- 像素／折纸通过原有 appearance 事务修改同一存档；切换后刷新仍保持画风，不重新建岛。
- 会客厅地图采用主区域与右侧操作栏，桌面地图约 1520 × 844；窄屏侧栏移到地图下方。大厅新增明确标注的小岛地形预览与回岛入口。
- 联机角色使用服务器的实际 walking 和 direction；剩余路径不触发原地踏步，纠偏向量不用于旋转角色，相同时间戳不重置预测。
- 会客馆提前读取轻量元数据并异步解码图片，缓存按身份／访客岛范围隔离；后台读取不会替换正在填写的留言或草稿。手动重新读取仍执行新请求。
- 缺少世界标识的旧同行数据返回未建档状态，未选择伙伴时不访问空对象。

## 证据

[原生双画风回归](verification/v148/lobby-native.json)：首个身份响应 503 后继续启动；15 秒轮询 503 不跳转；真实外观事务及浏览器刷新保持同一存档标识；会客馆预热后开启约 181–182 ms；草稿保留、无系统小手、窄屏无横向溢出。每套画风观察 600 次实际居民状态，纠偏未改变服务器朝向。

[17 项身份／同行／动画专项](verification/v148/unit-regression.txt)通过。回归采用本机 Edge、虚构身份与隔离存档；不是其他实体设备或真人联机验收。早期无存档 ID 的测试夹具失败记录保留在私有 QA 目录，随后使用真实建岛格式重跑。

本机三个服务的 24 项实际 HTTP 静态内容与源码一致；更新没有写入用户数据、密钥或重启游戏服务。当前已打开的旧窗口需刷新加载。
