# V291 · 会客地图帧恢复与连续回执

## 行为

会客地图使用已有的单链可见帧恢复器。页面可见但没有收到动画回调时，用真实经过时间恢复一次绘制并重新请求原生帧；隐藏和销毁停止同一条循环，重新聚焦不会创建重复链。

角色收到新坐标回执时，插值包含当前可见绘制间隔，并受原导航时间、250ms上限和已确认路径约束。持续新回执不再每帧把进度归零。工作／步态的50ms视觉间隔与导航间隔分别计算，继续检查拐角、速度、朝向和未来路径。

## 已完成的针对性对照

双风格使用隔离的真实服务端和原生鼠标指令。地图正常出现后，仅停止交付可见页的 RAF 回调四秒，不修改时间戳或坐标。旧版服务端已移动约250像素、画面移动0；修复后画面继续移动约180像素。恢复回调后原生帧继续，未触发手动聚焦事件。使用同一移动与恢复断言，未扩大时限。

四项连续新回执回归曾全部失败，修复后通过；34项帧循环、已确认路线、碰撞、速度与朝向规则通过。完整默认规则1470项通过，无失败、跳过或取消；双风格可见帧中断及原有正常／丢失回执／服务繁忙运动回归共8例通过。验证后运行模块、检查脚本和默认命令的摘要保持不变。
