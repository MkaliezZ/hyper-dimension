# V259 · 原生素材校验与农田回执证据

V257 为集市价签增加了独立透明素材，原素材检查只允许珍珠杯使用独立图片，因此 Windows 与 Mac Intel 检查在价签处失败。校验现在直接核对已声明的独立素材映射：画风、文件名、裁切框、声明尺寸、解码后的实际尺寸，以及图片边界均须一致。原有图集裁切、透明边缘、相邻图案探针和 SVG 留白检查保留。

完整双画风原生检查覆盖 616 项产物；每项同时核对背包 SVG、场景画布和手持画布。首轮本地运行完成渲染后，因未指定本工作树不存在的 Python 解释器而停止；指定现有隔离验证解释器后完整通过。此结果证明渲染契约与边界，不代表所有图案的语义和美术均已验收。

农田检查增加肥料增减回执、配方和执行者的只读诊断字段。两处零肥料断言、NPC 正常运行、作物生长时间及全部输入和超时保持原样。Windows 双画风原流程通过，原 Mac Intel 收获重开后肥料多出一份的失败仍保留，尚不能宣称恢复成功。

游戏运行代码和默认规则套件未变，继承 V258 的 1376 项规则验证。未修改 README。参见 [证据范围](verification/v259/native-diagnostics.json)。
