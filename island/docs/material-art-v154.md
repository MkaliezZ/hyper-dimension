# V154 · 基础材料图集边界

双画风 50 种基础材料的图集行列间距并不完全规则。小麦、海虾和竹材的原矩形取样会混入隔壁物品的像素。现在沿原图透明间隔校准每个素材的横向与纵向边界，在 SVG、场景 Canvas 和手持 Canvas 中采用相同的裁切；保留原源区域、大小、缩放比例及源 PNG。

SVG 还单独约束原源区域的矩形，避免 `preserveAspectRatio` 留白中漏出图集其他内容。工具握持、茶炉杯子和半身角色的专用裁切继续使用各自逻辑。

## 原生渲染检查

[公开的脱敏记录](verification/v154/native-material-clips.json) 对两套实际图集的全部 100 个材料图标进行了浏览器渲染，覆盖背包 SVG、场景和手持共 300 个显示面。100 个图标均非空，SVG 留白检查通过；四处已知邻图探针在 SVG 和两种 Canvas 中回到背景色，容差仍为 3 RGB。截图由开发 Agent 查看，不是玩家或真人美术验收。

此记录仅证明本次裁切修复及上述渲染检查。它不代表 300 个配方的全部用途、美术语义、所有动画和声音、25 馆独立小游戏品质或完整产品验收已经完成。完整 18R / 28F / 30T 范围保持不变。

## 25 馆的制作闭环检查

另一个 [不可变 V153 安装副本的原生检查](verification/v154/native-all-rooms-v153.json) 覆盖两套画风全部 25 馆。鼠标与键盘实际操作、正常墙钟演出、在建筑弹窗内领取、唯一服务端制作回执、390px 结算布局和刷新保留通过。

该检查预先给予全部物资、开放建筑及研究，并由测试操作程序读取关卡解法；不触及用户数据或调用模型，不修改运行中状态或时钟。测试程序遗漏服装分类切换、上一音乐关卡的松键及异步重开等待造成的失败均保留；音乐输入修正后通过。另记录一个待优化体验：结果保存核对时，重开按钮仍可点击但会被忽略，需明确等待状态或排队执行。

此结果证明这些关卡的制作闭环可完成，不代表从零采集、玩家可学性、随机难度质量、真人体验或独立发布品质。
