# V247 · 导入预览与本窗口自动保存的竞争

## 发现与修复

[原 Windows 运行](https://github.com/MkaliezZ/hyper-dimension/actions/runs/38993457420/job/117280656688)的签名导入被 `save_conflict` 拒绝。隔离截图显示服务端拒绝了过时版本，原进度没有被导入文件覆盖。

预览此前在读取服务端版本后才暂停本窗口写入；读取期间自动保存可能先行，较早的保存等待者也可能启动下一次写入。现在先排空已经开始的保存，再在读取版本前暂停新写入，并在读取失败后释放暂停。另一窗口确实修改了进度时，导入仍会被拒绝；签名、版本、备份及原编号重放规则保留。

## 验证范围

- 确定性行为基线复现 1 项失败；修复后新增 4 项检查及相关 15 项规则通过。
- 双画风共 6 个原生历史恢复／签名导入／恢复响应丢失案例通过。导入期间实际延迟 HTTP 读取，本窗口新保存被暂停；丢失的导入响应按原编号重放，恢复响应丢失没有重复执行恢复。
- 完整必需规则通过。计数与逐案结果见[证明摘要](verification/v247/recovery-import.json)。
