# 核对进度与未完成作业

原有“核对进度并收起提示”只读取服务端并刷新；服务端仍保留未完成的制作、农活等作业，重开后会再次显示同一个恢复面板。

现在已核对的未完成作业显示“继续作业”和“取消未完成作业并回岛”，不再提供反复刷新同一作业的核对按钮。有待确认回执时，先按原编号核对；核对本身保留未完成作业，不会擅自取消。

单独的取消回岛按钮只取消界面上那一项作业，校验类型、编号、代次和序号。取消前先持久化请求；若回包丢失，再次核对复用原编号。服务端已经确认的成品和收益不回滚，未消耗的材料预留按取消回执解除。其他作业变更会停止取消，要求重新核对。恢复期间不生成新的离页应急暂存，成功提交后清除过期应急记录。

实际浏览器回归使用临时 LAN 服务与虚构账号，两画风覆盖未完成肥料制作、居民遗留作业、取消回包丢失、材料与唯一回执、三次刷新和正常背包操作。它不读取用户浏览器或用户存档，也不代表全部长期游玩问题均已排除。

## 联机推进

游客出行现有入口包括必带本人管家、最多两位同意随行的居民、主岛会客地图、跨岛居民相遇及返岛档案。此轮新增双向混合画风的出行回归，核对原岛身份、管家自定义姓名与形象、同伴席位、重连和返岛保存。

管家信息交流、活动准备与原机连接分别使用既有的 A2A、受保护活动账本与设备桥接。继续检查真实双方 Hermes/Flash 回信和重试记录；物理多设备、真实四人长时体验和通用跨岛供应链需单独完成，不能由同机浏览器测试代替。

本轮真实双管家信息交流在两画风下完成：双方各自的 Hermes／deepseek-flash 回信、上一轮运行关联、丢失回包后不重复调用、刷新后查看往来记录均通过。验证在同一 Windows 主机的隔离账号和进程中进行，不宣称真实跨设备或通用联合活动已经完成。
