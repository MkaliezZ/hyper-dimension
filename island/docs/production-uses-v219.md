# V219 · 工作室组件与耐用画笔

棉布画板成为画作的实际画面，不再绕过画板重复取原木料。书籍修复包用于故事收藏箱中日志、诗集的整补护封，海风镜头安装到星空摄影架。现有物品编号、58素材、308配方和图鉴集合保留，配方依赖仍须通过真实库存、解锁、预留和结算。

竹木画笔改为耐用作业工具：可在背包或装备页选择，绘画时预留同一支，结束或取消后解除预留。自有画笔只缩短制作收尾动作20%，绘画关卡本身的时间、完成条件和评分不变。没有自有画笔仍可借用工作台工具，不会凭空获得库存。居民使用自己的公共工作用具，不占用岛主这一支。

像素与折纸各增加单支透明画笔图，按各自测量后的轮廓与握点绘制，使用完整连续角色和手掌前景层。既有图集保留；[素材来源和提示规格](../public/assets/art-provenance-v219.json)记录两张新图。

已经开始的制作继续使用保存的独立配方契约，升级不追补新原料、不重建作业编号。新计划按新依赖列出画板等前置步骤；画笔为可选自有工具，不形成从零开局的强制门槛。

规则与实际页面证据分别收录在[验证摘要](verification/v219/production-uses.json)，不把加速单元回放当作实际游戏时间，也不把隔离素材测试称为真人质量验收。
