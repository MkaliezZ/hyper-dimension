## 录制方法

- 全部游戏镜头使用当前 V135 界面与 V134 连续分块地形，没有拼入 V107／V108 的历史游戏录像。
- 原生浏览器标签捕获 2560 × 1440、60 fps；操作采用实际 UI、鼠标拖动、滚动和真实小游戏动作输入。
- 无人物位置／库存注入、游戏加速、光流补帧或帧混合。剪辑省略 AI 等待和部分游戏过程，保留实际通关与文件结果。
- 固定画幅加双语字幕；运镜来自游戏中的平滑拖拽。捕获启动与房间初载的较长帧区间未用于成片；选用的 32 段区间没有超过 50 ms 的捕获间隔。
- 季节预览录制夹具使用正式共享时令接口；经营时间与 NPC 速度未改动。最终 30／45 秒片的岛屿镜头为夏季。
- 使用项目原创《Island Hours》配乐，96 BPM；AAC 双声道 48 kHz。30 秒片平均音量 −22.7 dB、峰值 −7.5 dB。非第三方未授权曲目。
- 只使用隔离虚构资料，文件路径在录制界面遮罩。公库不含原始 API 回答、运行账本、密钥、真实存档与现实文档。
