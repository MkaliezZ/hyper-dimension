# V319 · 温室推箱检查的暂停续玩

Intel Mac 的温室检查在推箱关卡中遇到正常暂停，但自动游玩脚本继续点击暂停对话框下面的方向键，直到原点击时限耗尽。该次折纸风仍完成制作、生长和收获；像素风的失败日志明确记录了暂停对话框拦截。

脚本现在仅在关卡仍处于游玩、确实暂停且没有结果时，通过真实“继续”按钮恢复。续玩前后核对关卡阶段、结果、角色与箱子位置、移动数一致，关卡计时不倒退。待执行的方向输入保留原超时；恢复、结果及结算对话框不能被此处理绕过。

在同一份已发布 V318 游戏运行时上，先以真实暂停按钮复现旧脚本在两种画风下失败，再用修正脚本完成两种画风的继续、原配方扣料、制作一袋肥料、施肥、完整 180 秒自然生长、收获及刷新唯一结算。像素与折纸实测生长等待分别为 184.970 秒和 185.535 秒。夹具仍只提供原配方原料、种子、资金和建筑解锁；没有设置成品、成熟作物或通关结果。

定向托管检查分别执行普通流程和主动暂停流程；仍待当前提交的 Intel Mac 结果确认。游戏运行代码、难度、作物时钟和经济规则没有修改。本次范围不代表四岛完整流程、自然一小时、真人或物理多设备验收。见[机器可读记录](verification-v319.json)。
