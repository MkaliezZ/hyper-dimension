# V313 · 原生绘画检查的暂停续做

旧提交的 Intel Mac 绘画检查在折纸风第 2 笔停住，游戏时间保持在 23.104 秒。隔离截图明确显示“画面暂时停顿，挑战已暂停；继续后保留当前进度”。界面处于正常的安全暂停，制作传输未暂停、没有待核对检查点，制作请求均成功。原自动检查继续发送画笔坐标，却没有点击“继续挑战”，最终耗尽原有手势循环。

现在自动检查识别暂停弹窗，并点击真实的“继续挑战”按钮；检查恢复前后的笔触、弧长、墨量、颜色、分数、已完成报告和关卡身份保持一致。另提供显式夹具：已有完成笔触且当前笔触已前进后，点击真实暂停按钮，再通过同一继续按钮返回。产品暂停规则没有改变，也不在测试中直接改写暂停标记、时钟、成绩或库存。

原有 1800 次手势循环、自然游戏时间、品质门槛、工具预留、画布消耗、唯一作品回执及刷新保留检查全部保留。强制中途暂停已在双画风中完成实际制作与刷新；普通流程随后单独核对。没有产品规则或默认规则输入变化，沿用 V312 的 Node 22.13.0 / 25.8.1 各 1617 项结果，不把它称作本次重新跑过全部规则。

完整托管矩阵、Intel 绘画专项及当前交付包仍待确认。[机器可读范围](verification-v313.json)。

本地普通与强制暂停两组、共四个画风场景全部通过；原有通关、品质、材料和唯一回执检查均保留。托管 Intel 专项仍待执行结果。
