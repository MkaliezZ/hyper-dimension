# V175 · 居民工作与归家作息

## 统一时钟

单机居民读取 `worldEnvironment().sample()`；联机会客厅的常住居民读取同一服务端环境时钟。16 名常住角色各有固定工作、睡眠与起床时间，并对应自己的住所。钓手、烘焙师较早开工；音乐家和观星者较晚结束。自由相遇窗口按视觉日与角色身份确定，同一天不会在每次刷新或思考时重新随机。

- 工作时间继续原有职业备料、生产与维护链。
- 非工作时间优先个人兴趣、吃饭与休息；相遇窗口允许关系对话。
- 到睡眠时间沿可行走路线回自己家，到达后才在地图隐藏。
- 已经开始或正在确认的生产动作先完成；尚未执行的任务保留，次日继续。
- 起床后从家门口继续走向当天的目标。
- 管家角色归家不影响 Hermes 对话和现实任务入口。已获邀的夜集、钓鱼、集市、穿搭与烟花活动会从原家门叫醒参与者，按真实路径签到，散场后根据当前时钟回家；未参与的居民继续休息。正在申请或确认的田间、矿洞与制作作业须先收尾，派对不能取消这些租约；来访队伍依旧遵守岛主随行约定，不被安排进其他岛居民的家。
- 自动模型频率保持原值：规划 300 秒、对话 600 秒、管家 950 秒。

## 季节农作

自主播种遇到已结束种植季的空田时改用四季可种的小麦。具名作物的分工与居民合作保持目标，不会悄悄替换交付物；等待适宜季节。已经种下或成熟的跨季作物仍可以照料和收获。

## 验证范围

`tests/v175-resident-schedule.test.mjs` 验证两种画风的 16 位角色实际寻路回各自家、逐步位移速度、路径不穿水或建筑、起床与原队列保留；联机常住居民同步归家；夜间已接受回执只收尾一次；管家夜间手动入口与模型调用数量；季节播种与跨季委托。

`tests/v175-resident-party-sleep.test.mjs` 另验证两画风的夜间受邀签到、散场归家和所有五类活动等待未确认工作；非参与者的睡眠与位置保持。

这些是隔离规则与运行时测试，不代表原生浏览器视觉、真实模型回复或多人长期体验已完成验收。角色住所内部目前仍沿用现有展示卡，新增作息不新增卧室小游戏。
