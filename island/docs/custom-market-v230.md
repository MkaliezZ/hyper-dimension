# 共创商品的经营闭环

后台审核并发布的共创物品，可以在所属建筑的货架中手动上架。物品详情展示用途、后续配方、可能购买的游客、售价、保留数量与实际可售库存，并可直接进入该馆货架。

## 从制作到销售

1. 配方按材料与前置工序制作；居民和管家的正式筹备可交付成品。
2. 玩家选择商品并保存货架，设置留用数量。共创商品在发布后等待手动上架。
3. 有合适喜好的游客会把实际有货的商铺纳入行程，按设施品质与个人预算决定上岛、到店和消费。
4. 游客开始服务时预留一份商品并确认本次价格；完成后扣除商品、收取营业额和运营费，写入经营记录。
5. 后续出售使用剩余库存；任务、制作、派对及其他游客已预留的物资受到保护。

## 库存与经济

- 非食品的留用输入默认一件，食品默认零件；可自行调整为 0–9999。留用品仍可由玩家制作、使用或赠送。
- 共创售价沿用审核配方推导的保守价格，范围为 2–24 岛币；运营费向上取整为售价的 30%，至少一枚。游客保持现有预算、渡船班次、人数和行程上限。
- 改价、下架或收起图纸后，已经确认的交易仍按原价格完成；同一回执只结算一次。
- 图纸收起后保留已有成品的名称、图像、用途和所属建筑，现存成品仍可陈列与销售。
- 服务端保存精简的货架物品与建筑映射；实际玩家存档始终按该岛已发布目录校验。客户端提供另一岛的编号或自行添加映射不能获得售卖权限。

## 验证与边界

新增规则覆盖上架、留用、任务预留、定价、预算、停用、回执重放、磁盘重开及伪造输入。双画风原生流程检查实际图片解码、用途与货架往返、手机宽度以及游客乘船、上岛、行走和消费。

额外流程从无共创成品、声明原料的虚构岛开始，通过真实筹备 UI 与居民正常工作时间完成前置和成品、领取后上架，等待实际游客购买。这里的原料与测试 PNG 均为隔离夹具，不等于从零采集、成品美术、真人课堂或物理多设备验收。
