# V335 · 绘制队列的过期与健康判断

角色的一张姿态贴图可能在队列中等待较久。此前，只要其中一张超过十五秒，前端就会关闭整个绘制 Worker，并清空已经缓存的姿态；即使其他姿态仍在正常完成，也会受到影响。

现在，每张姿态保留原有十五秒期限。若其他姿态刚完成，则仅取消过期的那张；队列中的旧请求按键和请求编号共同匹配，不能取消同名的新请求。正在 GPU 上绘制的旧请求先完成复制，再关闭其结果并释放表面，避免覆盖、重复关闭和误画。连续十五秒没有已完成输出、图像复制失败或 Worker 真正报错时，仍走原来的故障保护。

## 验证范围

23 项相关检查通过，覆盖请求容量、字节预算、迟到结果、取消编号、GPU 表面所有权和无输出故障保护。隔离的真实浏览器对照使用原有十五秒定时器，明确延迟一张已经完成的贴图回包，同时让三个真实 WebGL2 姿态正常完成：原版关闭一次 Worker，修正版保留 Worker，并继续完成新的同名请求；迟到位图被正确关闭。它是图形故障注入验证，不是自然游戏、真人或物理多设备验收。

GPU 程序、贴图、网格、分辨率、姿态插值、内存预算和原图交接方式保持原样。本次不采用尚未通过完整验证的 CPU/PBO 读取、FIFO 或 UI 实验。

四地图同时运行仍存在海面首帧超时与焦点/刷新稳定性问题；完整随行 NPC、原机管家 A2A、联合活动、最终视频和真人/OPC 验收尚未完成。详见 [验证记录](verification-v335.json)。
