# Agent 互动观察模式

初期实现由教师版网页调用访谈 Agent；学生通过语音或文字与它互动，不需要学生 Agent。若仅有文字输入，能观察发起、回应、信息完整等文字交际行为，不能据此评分听力、发音或口语可理解度。口语正式证据需要可用音频、采集告知及教师可回听的引用。

## 两种模式

- 诊断模式：固定题目、Agent 角色、开场语、允许追问、提示规则和终止条件，全部带版本。Agent 可根据学生回答走预设分支，但不能即时改写目标、增加暗示答案的提示或替学生补话。不同学生使用可比较的条件；偏离时记录，必要时重测。
- 练习模式：Agent 可灵活追问和给予脚手架，重点是帮助学生练习。记录成长证据，但不直接与诊断模式的分数比较。

## 一轮口语任务的执行

1. 预检音频权限、环境噪声、播放音量和录音同意；缺一项时可切到文字练习，不能假装完成语音诊断。
2. 加载 item_id、interviewer_version、考官状态机、允许提示及观察量规。Agent 扮演新同伴，不扮演老师讲答案。
3. 每轮保存 agent_turn、student_turn、音频引用、ASR转写、开始/结束时间、提示类型、提示次数、设备/识别置信。保留学生原始表达，不把自动纠错后的文本当作原话。
4. 观察任务意图、主动发起、信息完整、回应与澄清、可理解度；每条判断引用具体轮次或音频时间片段。ASR 低置信、环境噪声或超出脚本时返回 uncertain 或 invalid_attempt，安排补测。
5. Agent 只生成结构化草评与可解释依据。教师可回听、修改、批准或撤回；学生/家长可见报告只使用批准版本。

例如三年级“认识新同伴”题：Agent 先说 Hi 并等待。学生若介绍自己并询问姓名，Agent 按脚本回答，再问能否分享。若学生沉默，Agent 只给一次允许的提示并记录为受提示完成。评分看学生完成的交际行为，不要求与示例台词逐字相同。

## 记录与审计

一次 attempt 至少有 item/version、interviewer/version、mode、turn_events、hints、media_quality、observations、scorer_draft、teacher_decision、audit_refs。事件按时间顺序不可静默覆盖；重测创建新 attempt。原始音频和真实学生信息留在受控存储，对 Agent 间仅返回授权的对象引用。未来学生 Agent 可通过 Hyper Dimension 业务协议提交同一结构的证据，A2A 只负责传输。
