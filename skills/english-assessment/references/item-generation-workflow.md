# 原创英语题目生成流程 v0.1

适用：6—15 岁英语诊断、短测、周测或较长的读写卷。此流程用于在教师预授权策略下实时产生**待服务端质量门验证的题包**，不自动宣称官方中考、A2 Key、B1 Preliminary 或 CEFR 等级。当前优先读写；听力与口语只有在真实媒体和相应规则准备好后才纳入。

## 1. 接收任务并确定测量边界

确认年龄/年级、教材版本与册次、已授课进度、地区卷型（若需）、时长、测评目的、已练情境、设备条件、输出格式和教师预授权策略及异常复核责任人。把未施测的技能列为 missing。缺教材页证据时可做跨教材能力任务，但题包标记“教材映射待核”，不能写成已对齐某册某单元。

先写一句可观察目标，例如“读两条相互更正的通知，找出最终会合地点”；避免先选 AI 等话题、再倒推要考什么。

## 2. 建证据卡，区分事实与借鉴

- **本地教材**：按出版社、书名/系列、学制、年级、册次、版本逐页记录实际知识和语言行动。记录相对路径、PDF页与印刷页、审阅人、状态。目录级信息不能支持逐页语言点结论。教材页不进入公库。
- **本地考试**：地区+年份+考试名称必须同时核对。优先考试机构或政府公开的原题/评分细则；其次原命题部门试题评析；媒体转述只标为二级证据。仅有评析时不能声称取得完整真题。2026 北京“当运动遇见 AI”是高考，不能误作中考。
- **国际参照**：阅读 Cambridge 官方 A2 Key/B1 Preliminary 考试格式和样题说明，提取任务功能、信息处理方式、体裁与评分维度。记录 URL、查阅日期、考试版本；不复制题目、长段原文、图片、录音或私有题库。
- **CEFR**：只标具体 can-do 的候选关联及出处；不按国内年级或原始分自动换算等级。

对于当年热点，先看真实试题中的**任务**，再选适龄情境。2026 已核对样本表明科技可出现在阅读或听力，写作也可能考环保、护眼和实践；不要把“所有作文都写 AI”固化成命题规则。公开样本与证据边界见[2026 年中考英语任务核验](../../../docs/curriculum/2026-exam-task-review.md)，正式再出题时重新核验来源。

## 3. 冻结蓝图再写题

蓝图至少记录：blueprint_id/version、教材证据、国内考试参照及证据级别、剑桥任务参照、能力节点、目标交际行为、熟悉/迁移情境、题型与分值、时长、难度梯度、覆盖缺口和教师策略版本。题型随目的选，不能为了“像 KET/PET”硬凑完整卷。日测以一次可观察行为为主；长测混合基础语言、功能文本、跨文本理解和输出。读写原始分不直接换算当地英语总分。

优先把真实任务写成“谁需要什么信息—材料给出什么—学生据此要做什么”；同一试卷保留不同主题，避免整卷被单个热点词支配。

## 4. 编制题目和标准答案

每题绑定 item_id/version、原创来源、目标能力、教材页或待核状态、预计用时、题干、刺激材料和答案依据。选择题有且只有一个最佳答案；每个干扰项对应可解释误读，例如只抓关键词、忽略更新信息、推断超过文本证据、混淆事实与观点。禁止为了凑选项造两个都成立的答案。开放题说明可接受的其他表达。

写作先确定受众、目的、需要完成的行动和可用信息，再确定词数。评分至少分内容、交际效果、组织、语言；量规写清“怎样完成任务”，不按是否赞同 AI、是否使用复杂术语给分。提供适龄范文并核对词数、题干要点和量规一致。若涉及 AI，测量信息核实与自主表达，不考模型原理；不给未成年人题目索取真实同学姓名、照片、联系方式。

## 5. 三轮质量门

1. **事实与版权**：教材版本/页码、地区年份、考试级别、来源证据层级、素材授权、无学生隐私。
2. **题目与测量**：答案唯一、逐项干扰理由、难度符合年龄、课内语言可迁移到新情境、题干与素材足以作答、评分不因立场偏差。
3. **交付一致性**：学生卷与教师答案、解析、分值、总分、范文字数、蓝图、题包 JSON 一致；Word/PDF 渲染查分页与漏题；结构化题包运行 `scripts/validate_bundle.py`。教师在启用策略前审核样题、量规和权重；实时题包必须逐次通过自动质量门，异常再交教师复核。

任一轮失败就退回相应步骤并递增题目版本，不悄悄覆盖已作答版本。只有题包满足已获教师授权的策略及质量门，服务端才标为 published；不满足者保持 draft/needs_review，不对学生发布。

## 6. 施测、诊断和迭代

保存 item/version、学生作答引用、提示、时间、设备问题与评分版本。客观题按答案键；开放题 Agent 按版本化量规和教师固定权重给出带原句证据的评分，合格结果由服务端按预授权策略自动批准；异常交教师。错因是候选，不由单题错误断定稳定缺陷。下一次用**未练过的新情境**复测相同能力节点；报告记录覆盖缺口、教材进度、优先目标与四周计划，并经教师预授权策略自动批准或异常人工复核。所有信息留可审计引用，为未来学生 Agent/A2A 适配预留业务对象 ID。

交付至少包括教材证据卡、命题蓝图、原创学生卷、教师答案/逐题解析/量规、结构化题包、质量门记录和审批状态。字段形状见 [output-contract.md](output-contract.md)，能力与节奏见 [assessment-design.md](assessment-design.md)。
