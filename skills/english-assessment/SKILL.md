# English Assessment

本 skill 是可移植的测评工作流。当前首期先交付阅读与写作出题；口语评价方式待定，Agent 互动仅保留为可选设计；听力先保留音频制作规范，不作为现阶段必测项。用户指定的教材 PDF 根目录是输入，绝不假定盘符、固定目录或已有授权。先阅读本文件；生成或修订题目时必读 [题目生成流程](references/item-generation-workflow.md)，再按任务读取 references/assessment-design.md 与 references/output-contract.md。输出可以是结构化 JSON、可读的题目包及报告；对真实学生只保存受控引用。

## 先确认输入

询问或从现有上下文确定：学段、年龄、教材出版社/系列/主编/学制/年级/册次、学校实际进度、测评目的、时间、是否有听力音频及口语采集条件、教师预授权策略及异常复核责任人。缺少教材时可做跨教材能力诊断，但不能声称对齐具体课本。没有音频不把听力记为已测；没有互动证据不把口语互动记为已测。

## 工作流

1. 逐册确认封面或版权页、目录和目标单元实际页码。记录 PDF 相对路径、页码、出版社、版本、来源和审阅状态；扫描版先 OCR 或看图复核。教材只提供知识与情境坐标，不直接成为试题文本。
2. 按 references/assessment-design.md 选择适龄轨道和能力目标。6—8岁先从 Pre-A1/A1 适龄任务开始；A2 Key for Schools、B1 Preliminary for Schools 是题型与能力框架参照，不按年级直接贴证书等级。
3. 按题目生成流程先核验当年地区试题的来源级别，比较国内任务与 Cambridge 官方任务构念，冻结蓝图后设计教材相关与未练过的新情境阅读、写作任务；阅读考察获取信息，写作考察表达意图。阅读题型须覆盖选择题，不以匹配题代替 KET/PET 的全部阅读逻辑；每个选择题要有唯一答案和干扰项理由。其他技能在蓝图中明确标记未施测，不为了凑四技能而假造证据。每题保留教材页证据、CEFR can-do 参考、内部能力节点、难度理由、正确答案或分析性量规。
4. 题干、短文、对话、音频脚本和图片必须原创或有明确可用授权。AI 等科技话题只在适龄且能测到目标能力时使用，不把某年某地的热点写成全国固定作文题。未来需要听力题时先读 references/listening-audio.md；固定测试先生成并审听音频，再发布题目。只抽象参考剑桥公开样题的构念、题型、题量与评分维度；不复刻题目、长段原文、图片或录音。教师预先批准蓝图和抽样题包；每次实时题包发布前由服务端质量门检查事实、难度、答案唯一性、偏差和可访问性，失败则进入异常队列。
5. 如由 Agent 扮演互动对象，先读 references/agent-interview.md，锁定考官脚本和允许的追问范围；练习模式可灵活追问，诊断模式必须可复现。收集作答时记录题目版本、每轮话语、时间、提示、设备质量和原始证据引用。客观题按答案键判分；首期写作由 Agent 按量规评分并标出证据片段、替代解释和不确定点，按教师已批准的策略和固定权重自动批准合格结果；证据不足或质量门失败时进入复核。口语评分方式待定。
6. 生成逐题解析、错因候选、能力画像与四周计划。把观察与推断分开；证据不足返回 insufficient_evidence 并给补测任务，不强行给 CEFR 等级或 Cambridge English Scale 分数。报告在服务端验证教师预授权策略与可见范围后可自动发布；异常需复核。年龄、年级只用于选题起点，能力结论依赖作答证据。详见 [实时测评与审计契约](../../docs/curriculum/realtime-assessment-and-audit-v0.1.md)。

## 交付与约束

按 references/output-contract.md 交付教材证据卡、测评蓝图、原创题目包、答案/量规、逐题解析、错题记录、报告及自动批准/异常状态。阅读写作样例见 examples/reading-writing-grade7-unit1.json；口语 Agent 交互样例留作未来可选设计。日/周/月/学期节奏沿用项目测评设计；一次短测不能当标准化考试。不同学生的共同班级目标可相同，脚手架与起点由证据决定。保存版本、来源与审计引用，为未来学生 Agent 与教师 Agent 的 Hyper Dimension 业务协议 / A2A 传输提供对象引用。

公开分享 skill 时不附教材 PDF、剑桥样题全文、学生答卷、录音或个人信息；当地题库、教材页与真实学生证据应留在受控存储。报告必须标注“本项目教学诊断，非 Cambridge 官方考试或 CEFR 认证”。
